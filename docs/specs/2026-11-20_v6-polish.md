## 1. Intent

- **要做什么**：修掉 Neo 在真实 DSH 里遇到的问题，并补上他点名要的功能：
  1. 输入框聚焦时出现两层框（首页、紫微师、表单都有）。
  2. 关掉首页 3D 星图后，右上角的按钮点不动。
  3. 首页问「你好」得到「模型返回为空」。
  4. 去掉左上角的「返回会话」按钮。
  5. 加模型选择，参考自媒体工作台（`dsh-media-desk`）的做法。
  6. 面板自己管深浅色，默认深色，设置里能切到浅色或跟随 DSH。
  7. 紫微师的引导问题常驻，不是只在空对话时出现。
  8. 命盘页：格局不随选宫和时间变，放进同样不动的中宫；左栏补上有用的信息。
  9. 把同类小问题一起查一遍。
- **为什么**：v6 第一次在真实 DSH 里用就暴露了预览壳没覆盖到的问题（宿主的焦点样式、真实模型只思考不作答）。这些问题单个都不大，合在一起让人觉得粗糙。
- **约束**：
  - 禁区不变：不手改构建产物，不改 `package.json` 的 `name` / `private`，不碰 `~/.dsh/profiles/*`，不重启 DSH，不发布，不加 npm 依赖，只用黄金用例。
  - 本机记录向后兼容：只新增 localStorage 键（`ziwei-pro.theme`、`ziwei-pro.model`），旧记录原样可读。
  - 排盘结果不变：`src/engine-core.js` 不动。
  - Host 半（`index.js`、`src/ziwei-core.js`）这次要改，改动要 Neo 重启 DSH 后才生效；Client 半在旧 Host 上必须照常能用。
- **不做什么**：不 push、不合并、不发布；不改报告的 14 部分结构；不做流式思考内容的展示；不做多模型并行。
- **成功指标**：
  - `node build.mjs && node verify/all.mjs` 全绿，`node scripts/audit-ui.mjs` 0 失败 0 警告。
  - 预览壳（带上宿主的焦点样式）里深色 / 浅色 × 窄 / 中 / 宽逐屏看过，上面 1–8 条都能复现「改之前有问题、改之后没有」。
  - Neo 重启 DSH 后在真机里复核。

## 2. 用户故事

1. 作为在首页打字的人，我点进输入框只看到一圈干净的高亮，不是两层框。
2. 作为关了 3D 的人，我照样能点右上角的「全部命盘」和「设置」。
3. 作为随口打了句「你好」的人，我得到一句正常的回应；模型偶尔只思考不作答时，面板自己再试一次，实在不行告诉我怎么办。
4. 作为有几个模型可用的人，我能在提问的地方看到现在用的是哪个模型，点一下换一个。
5. 作为 DSH 用浅色的人，我打开紫微面板默认是深色的星空，想换浅色在设置里点一下。
6. 作为聊到一半的人，我不用自己想下一句问什么，输入框上面一直有几个和当前这一宫、这一层时间有关的问题。
7. 作为看盘的人，我在中宫一眼看到这张盘的格局；在左栏能直接跳到某个大限、某一年、某个月、某一天，并看到选中宫的三方四正里有什么星、宫干四化飞到哪。

## 3. 验收标准

### 3.1 焦点和输入框
- 当文字输入框（首页提问、引导问答、紫微师、生辰表单、改名）获得焦点时，只有一处高亮：输入框自己（或它外面那个圆角容器）的描边变色并带一圈淡光晕；输入框本身不画 `outline`。
- 当用键盘 Tab 到按钮、页签、宫格时，画 2px 的焦点框，颜色用面板的紫微色；宿主在鼠标点击时把非输入控件的焦点框隐去，面板不覆盖这个行为。

### 3.2 没有 3D 时的首页
- 当「首页 3D 星图」关着（或没有 WebGL）时，顶栏的按钮可以点；星球标签的菜单仍然能盖在对话栏上面。

### 3.3 模型没有作答
- 当模型正常结束但正文为空时，Host 在同一个请求里自动再问一次（最多一次），第二次用这个模型最低的思考档位（模型没有档位信息时不带），并在消息末尾加一句「请直接给出回答」。
- 如果第二次还是空，返回 `kind: 'empty'`；面板显示「模型只做了思考，没有给出回答」，并给「重试」和「换个模型」。
- 当用户只是寒暄、道谢（没有命理问题）时，提示词要求模型用一两句话回应并说明可以问什么，不套「结论 → 依据 → 建议」的结构，不凑字数。
- 如果用户在第二次尝试期间点了停止，照常停止。

### 3.4 返回会话
- 顶栏不再有「返回会话」按钮。命盘页顶栏第一个控件是回首页的「星图」。
- 出口保留两处：设置弹层最后一行「回到 DSH 对话」；面板最外层出错时的错误页。`layout.selectPanel(null)` 不可用时两处都不渲染。
- 侧栏折叠时宿主放在左上角的控件不能被面板盖住（`isolation: isolate` 和 `--dsh-frame-leading-clearance` 的避让都保留）。

### 3.5 模型选择
- Host 提供 `GET /ziwei/models`：`{ ok, providers: [{ id, name, models: [{ id, name }] }], default: { provider, model } | null }`。列不出模型的提供方不出现。
- `/ziwei/interpret` 的请求体可以带 `model: { provider, model }`；带了就用它，不带用 DSH 的默认模型。字段不是字符串、超过 200 字或只给了一半时忽略。
- 面板把选择存在 `ziwei-pro.model`（`{ provider, model }`，没有这个键 = 跟随 DSH 默认）。
- 紫微师输入框和首页提问框上有一个模型按钮，显示当前生效的模型名；点开是模型选择弹层：第一项「跟随 DSH 默认（<模型名>）」，下面按提供方分组列出模型，当前项高亮。选了之后提示「已切换到 <模型名>」，下一次提问生效。
- 如果 `/ziwei/models` 读不到（旧 Host、还没重启），弹层说明「读不到模型列表，重启 DeepSeek Harness 后再试」，其余功能不受影响，提问仍用 DSH 默认模型。
- 如果选过的模型后来不在列表里了，按钮仍显示它；调用失败时错误条给「换个模型」。

### 3.6 主题
- 偏好 `ziwei-pro.theme` 取 `dark` / `light` / `auto`，没有这个键按 `dark`。
- 根节点带 `data-theme="dark" | "light"`（`auto` 时按 `body[data-ds-dark-theme]` 解析，宿主切换时跟着变）。
- 面板的全部颜色来自自己的两套 `--zp-*`，不再读宿主的 `--dsw-alias-*`；首页的夜空 / 晨光跟 `data-theme` 走。
- 设置里「外观」一行三选一：深色 / 浅色 / 跟随 DSH。

### 3.7 引导常驻
- 紫微师输入框上方一直有一排引导问题（生成中禁用）：讲讲选中的这一宫、当前时间层级怎么样、两条通用问题；对话为空时最多 4 条，有对话后最多 3 条。
- 点「讲讲 <宫名>」带上这一宫的星曜作引用；点时间层级那条带上当前页签的定位。
- 首页的三个快捷项保持常驻；在引导问答中途打开了别的盘，回到首页时不再停在引导问答里。

### 3.8 命盘页
- 盘面够宽时（中宫放得下），格局在中宫：一排格局名，点哪个下面显示哪个的说明；左栏不再有格局卡。盘面窄时格局仍在左栏（窄档是第二个页签）。两处由同一个容器宽度条件切换，同一时间只显示一处。
- 三方四正的连线从中宫的文字下面穿过，不压在字上。
- 时间卡下面有「时间条」：本命显示此刻的大限、流年、流月、流日各一行，点了跳到那个页签；大限显示十二个大限；流年显示这个大限里的十年；流月显示这一年的十二个月；流日显示这个月的日历。当前项高亮，今天所在的那项有标记，点了直接跳过去。
- 宫位卡多三样：这一宫管什么；三方四正每一宫的主星；宫干四化飞到哪一宫。
- 一屏放完、不滚动的要求不变：左栏不够高时按「时间条 → 星曜解释 → 宫干四化」的顺序收起。
- 选宫只改宫格的状态属性、连线、宫位卡（验收项沿用上一份 spec）。

## 4. 设计决定

### 4.1 改掉的三条旧约束
| 旧约束（2026-11-19 spec） | 现在 | 原因 |
|---|---|---|
| 顶栏第一个控件是「返回会话」 | 去掉；出口在设置和错误页 | Neo 真机里觉得多余。当初加它是因为侧栏折叠时宿主的出口被面板盖住（`audit/03`），盖住的问题已由层叠隔离解决 |
| 系统色只用 `--dsw-alias-*` | 面板自带两套配色 | 要「默认深色、和 DSH 的主题无关」，就不能再读宿主当前主题的变量（ADR-0005） |
| 不改 `index.js`、`src/ziwei-core.js` | 加一条路由、一个可选字段、一次空答重试、一段寒暄规则 | 模型选择和「模型返回为空」都只能在 Host 半解决 |

### 4.2 涉及的模块
- Host：`index.js`（`/ziwei/models`、`handleInterpret` 的模型覆盖和空答重试）、`src/ziwei-core.js`（`QA_RULES`）。
- Client：`src/ui/css/*`（配色改名、焦点、作曲区、命盘页）、`21-storage`（两个偏好）、`24-scope`（时间条、宫位卡的数据）、`26-store`（主题、模型、`setWhen`）、`50-parts`、`60-home`、`66-settings`、新的 `68-models`、`70-chart`、`80-assistant`、`90-app`。
- 约定文档：`docs/ui-contract/{tokens,layout,design}.md` 先改，体检脚本跟着改。

### 4.3 数据
- 新增 `ziwei-pro.theme`（字符串）、`ziwei-pro.model`（JSON）。「清除对话与报告」不动它们。
- 会话态新增 `models`（模型列表的读取状态）、`lastModel`（最近一次回答实际用的模型，来自 SSE 的 `start` 事件）。

### 4.4 关键决定
- 配色：见 ADR-0005。深色是带一点靛色的夜空底，浅色是浅灰底加白卡片（宿主浅色下三层底色是同一个白，卡片分不出层次）。
- 空答重试放在 Host：面板不用知道重试，旧面板也受益；第二次的增量照常流给面板。
- 模型选择存在浏览器里而不是 Host 的设置文件：插件现在没有任何 Host 侧的持久化，不为这一项引入。
