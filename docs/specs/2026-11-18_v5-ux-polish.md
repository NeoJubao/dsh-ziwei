# v5 工作台体验打磨（交互 · 视觉 · 布局）

- 状态：已确认（Neo，2026-11-18，Plan mode 审批）
- Issue：无
- 计划：docs/plans/2026-11-18_v5-ux-polish-plan.md

## 1. Intent

- **要做什么**：修掉 v5 dogfood 里已经坏掉的交互；补足最常用宽度（compact，约 1000px）下的选中反馈；
  收掉重复信息与无效留白。
- **为什么**：用预览壳（宿主真实 token + 当前 `client.js`）实际渲染面板，并对代码做了一次交互审查。结论：
  报告续写会重复拼接；生成途中换盘会把旧回答写进新盘；深色模式下入口卡标题看不见；窄屏底栏的图标和文字拆成两行；
  compact 档点宫位后，详情落在首屏以下；四柱在顶栏、命主卡、中宫重复出现三次；1470×717 下盘面最后一行被切掉。
- **约束**：只动 `src/ui-pro.js`（L1）；不改 localStorage 的键和记录结构；不改区域白名单和三档阈值；
  只用现有 token，audit 欠账只减不增；不引入运行期依赖。
- **不做什么**：排盘引擎、Host 路由、中宫职责、v5 Phase 3（回访与记录）和 Phase 4（官方上架）、发布。
- **成功指标**：下面的验收标准全部可复现；`verify/all.mjs` 全绿；audit 计数不升。

## 2. 用户故事

1. 作为看盘的人，我在 1000px 宽的面板里点一个宫位，马上能在盘面上看到它的三方四正，详情也会滚到眼前。
2. 作为读报告的人，我中断后点「继续生成」，得到的是一份不重复的完整报告；中途换盘，也不会串到别的盘里。
3. 作为深色主题用户，解读抽屉里每一个按钮的文字都看得清。
4. 作为第一次打开的人，我分得清哪个是示例盘、哪个是我自己的盘。

## 3. 验收标准

**批 A（修坏的）**
- 当带图标的 `.zp-btn` 渲染时，图标和文字在同一行（`display:inline-flex`）。
- 当窄屏有盘时，底栏贴住面板底边，下方不露出盘面；底栏宽度不超出滚动区。
- 当深色主题打开抽屉空态时，入口卡标题的颜色等于 `label-primary`，不是浏览器默认黑。
- 当抽屉、阅读层、设置被程序聚焦时，容器不显示焦点框；内部控件的 `:focus-visible` 不受影响。
- 当报告中断后点「继续生成」并收到 `done` 时，最终正文 = 旧正文 + 本轮正文，不重复。
- 当报告或对话生成中换盘时，旧盘已写的内容按旧 key 落盘（标为中断，可继续）；新盘不出现旧盘的任何文字。
- 当报告正文滚动后选中一段时，「让紫微师改这段」按钮出现在选区旁边。
- 当引用宫位时，引用文本包含宫名、干支和该宫的星曜名。
- 当报告中断且已有正文时，正文照常显示，并会落盘。
- 当点「重新生成」时，需要在 4 秒内再点一次才执行；如果新报告失败且没有正文，恢复旧报告。
- 当全屏阅读被系统 Esc 退出时，按钮状态同步；再按 Esc 能关闭阅读层。

**批 B（交互）**
- 选中宫位时，盘面上的对宫和两个三合宫有可见标记；非 wide 档下，详情滚入视野。
- 方向键只在盘面视图里切换宫位。
- 抽屉关着时生成仍在进行，「紫微师解读」按钮上有运行标记；报告完成或失败时弹出带「查看」的提示。
- 点「速览解读」后，立刻看到「正在思考」。
- 切到报告页签再切回来，或关掉抽屉再打开，未发送的草稿还在（同一张盘）；输入法候选框打开时按 Esc，不关闭抽屉。
- 表单改过但没排盘时，存库和解读用的是这张盘排盘时的输入，并提示「生辰已改」。
- 窄屏下中宫和顶栏摘要标明「示例盘」；空态 CTA 一定排示例生辰。
- 下列各项见批 B 清单：复制、导出、清除记录的反馈；回到报告时的阅读位置；续写与重试；换盘残留；文案。

**批 C（视觉与布局）**
- 1000×760 和 1470×717 下，时间栏和四行宫格完整落在首屏。
- 左栏可见时，顶栏不重复四柱。
- 详情区里不可点的信息不画成按钮样式。
- 空态与表单等高，表单头部标明「示例生辰」；占位文字不截断。

## 4. 设计决定

- **模块**：`ProApp`（状态、换盘、流控制）、`StudioChat`、`StudioDrawer`、`ReportArtifact`、`ReportReader`、
  `PalaceCell` / `PalaceDetail`、`Icon`、`useDialogFocus`、CSS 段。
- **数据结构**：不改记录格式（`ziwei-pro.readings.v2` 的形状不变）。草稿、阅读位置只存内存。
- **纯逻辑出口**：仿照 `window.ZWReport`，新增 `window.ZWUi`，暴露报告续写合并、宫位引用文本、
  选段坐标、三方四正索引、表单与快照比对，供自检使用。
- **选宫反馈**：盘内高亮三方四正，不改中宫职责（Neo 拍板）。
- **按钮颜色重置**：用 `:where(.zp-root) button { color: inherit }`，权重 0,0,1，不覆盖组件色。

## 5. 测试决定

- `verify/verify.mjs`：为 `window.ZWUi` 的纯函数写断言；用 CSS 静态断言检查按钮布局、颜色重置、自动聚焦标记。
- 预览壳（不进仓库）：给 `/ziwei/interpret` 打桩，用模拟 SSE 回放续写、换盘、中断、重新生成；
  在 720 / 1000 / 1470px × 浅色 / 深色下截图。
- DSH 真机复核：拿到 `dsh web` 地址后补做；没拿到时，在提交说明里写「未做视觉复核（仅预览壳）」。
