# 界面契约 · token（tokens.md）

> **分工一句话**：`layout.md` 管「放哪里」，`design.md` 管「什么规则」，本文管「用哪个名字、值是多少」。
> 本文是插件自有的**值的权威**；DSH 系统色的值由宿主主题提供，**本仓库不拥有、不复制、不覆盖**——本文只登记名字与语义。

- 适用对象：`ziwei-workbench` 客户端面板（`src/ui-pro.js` 的 CSS 段 167–896 与 JSX 内联样式）
- 机器可读约定：`scripts/audit-ui.mjs` 会读本文的「私有变量登记」与「字面色白名单」两张表，作为 C1/C16 的判据。改表即改检查。
- 实测口径：引用次数 = `src/ui-pro.js` CSS 段中 `var(--x)` 出现次数（2026-11-07 实测，源码 2501 行）

---

## §0 一条切线的落点

| 问题 | 归属 |
|---|---|
| 背景、边框、文字、品牌、状态、遮罩、滚动条 —— **系统色** | 宿主主题（`--dsw-alias-*`），本插件只消费 |
| 星曜、四化、庙旺、吉凶、金 —— **内容色** | 插件自有（`--zp-*`），本文给值与边界 |
| 结构尺寸（盘面最大宽等） | 插件自有，但**名字与值须与 layout.md §3.3 一致**（`--zp-board-max` = `BOARD_MAX`） |

**允许写死的唯一一组 = §4 内容色**。除此以外出现 literal 颜色（`#hex` / `rgb()` / `hsl()`）即违规，由 audit C1 计数（§5 给出当前 13 处欠账）。

### 3.2 规则

规则：这两个名字**只许减少，不许新增引用**（audit C16 棘轮）。深色 `--zp-accent: #a78bfa` 不再用于白字填充（改用 §3.3 的 `--zp-fill-accent*`，白字 5.52:1）；它只做文字/描边色，在深色底上对比度 6.1:1。

具体做法：变量定义保留在 `.zp-root`（过渡期），**新增代码不得引用**；迁移时把 `var(--zp-accent)` 换成 `var(--dsw-alias-brand-primary)`，深色由主题给值，删掉这两行定义。

## §6 深色主题与对比度底线

规则（design.md §7 的 token 侧落实）：

1. **系统色**：不写任何深色覆盖，靠 `body[data-ds-dark-theme]` 下的 token 自动变。
2. **内容色**：每个 `--zp-*` 内容色都必须在深色块里**重新给值**（提亮一档）。当前浅色 10 个内容色 / 深色 10 个 —— 键集合完全相等 ✅（audit C15 校验）。
3. **填充上的前景**：品牌/金/四化填充上的字必须用 `--dsw-alias-label-primary-inverted` 或白名单深字；**禁止** `#fff` 写死。
4. **对比度底线**：正文 4.5:1、大字（≥18.66px 或 ≥14px 粗体）3:1、图形/边框 3:1。

实测对比度（WCAG 公式，取源码字面值）：

| 前景 | 背景 | 比值 | 判定 |
|---|---|---|---|
| `#fff` | `#7c5cf0`（浅色 accent） | 4.52:1 | ✅ 刚过 AA |
| `#fff` | `#a78bfa`（深色 accent） | **2.72:1** | ❌ **必修**（P0-2 = 本契约头号欠账） |
| `#fff` | `#5b3fd6`（浅色 accent-deep） | 6.72:1 | ✅ |
| `#fff` | 渐变中段 `#a78bfa→#7c5cf0` | ≈2.7–4.5:1 | ❌ 深色端不达标 |
| `#3c2f14` | `#c9a35c`（金·浅） | 5.52:1 | ✅ |
| `#2a2210` | `#d8b877`（金·深） | 8.27:1 | ✅ |
| `#8a7550` | `#f5f5f5`（假设 layer-1，**真实 token 值未知**） | ≈4.06:1 | ⚠️ 待 GUI 复核（9.5px 小字需 4.5） |

注：系统色 token 的真实明暗值不在本仓库（宿主主题持有），表中涉及 token 值的行标注为「假设」，不得作为验收依据。

## §7 使用边界

- **可以新建 `--zp-*`**：内容色（且有明暗两套值 + 白名单登记）、结构尺寸（且 layout.md §3.3 有登记）。
- **不可以新建 `--zp-*`**：任何系统色（背景/边框/文字/状态/遮罩/滚动条），一律直接消费 `--dsw-alias-*`。
- 内容色**不得**用于：页面底、卡片底、边框、状态提示（那些是系统色）、图表以外的装饰。
- 新增内容色必须同时更新：§4.3 白名单表（否则 C1 报红）、§6 深色对应（否则 C15 报红）、design.md §3 对比度结论。
- `--zp-accent*` 两个名字进入退役期：只减不增（C16）。
