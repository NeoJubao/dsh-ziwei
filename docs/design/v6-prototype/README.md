# v6 原型（设计参考）

v6 界面重做的可交互原型，2026-11-19 定稿（第 4 版）。它是**设计参考**，不是插件代码：插件里的实现在 `src/ui/` 和 `src/sky.js`，需求见 [`docs/specs/2026-11-19_v6-redesign.md`](../../specs/2026-11-19_v6-redesign.md)。

## 怎么看

```bash
node docs/design/v6-prototype/build.mjs      # 生成 dist/v6-prototype.html
open dist/v6-prototype.html                  # 需要联网加载 Three.js r128（cdnjs，带 SRI）
```

顶部的"原型"开关条可以切新用户 / 老用户、浅色 / 深色，以及重播开场。

## 哪些是真的，哪些是示意

| 部分 | 真 / 示意 |
|---|---|
| 排盘、大限、流年、流月、流日、格局 | 真：用仓库里的 `engine-built.js` |
| 3D 星图 | 真：`sky.js`，插件里的 `src/sky.js` 由它移植 |
| 紫微师的回答 | 示意：本地拼的示例文字 |
| 完整报告 | 示意：样稿。星曜、四化、格局、大限取自当前这张盘，解读文字是写好的；"写"的过程是快进演示 |
| 下载报告 | 示意：原型里只能预览导出文件的样子；导出文件本身的版式（`report.js` 的 `buildReportHtml`）是真的 |
| 命盘 | 五张示例盘全是编的生辰；"小林"用的是仓库的黄金用例（1992-05-03 09:30，男，经度 105.97） |

## 文件

| 文件 | 内容 |
|---|---|
| `body.html` | 页面骨架 |
| `style.css` | 全部样式。颜色变量是照着 DSH 的浅色 / 深色主题抄的近似值，插件里要换成 `--dsw-alias-*` |
| `sky.js` | 3D 星图「紫微天仪」：浑天仪、星球、尘埃盘、星云、后期处理；拖动、缩放、飞入飞出 |
| `report.js` | 完整报告：markdown 解析（和插件的 `mdToHtml` 同口径）、分部、浑天仪徽记、静态命盘、导出文件 |
| `app.js` | 界面逻辑：首页、引导问答、命盘页、报告页、紫微师面板 |
| `build.mjs` | 拼成单页 |

## 移植到插件时不照搬的地方

- 布局用了视口媒体查询（`@media (max-width: 720px / 1180px)`）；插件里按面板实测宽度分档。
- 字号、间距、过渡时长有不少落在界面约定的档位之外；插件里收到档位上。
- `#app { position: fixed }` 和"原型"开关条、导出预览浮层只属于原型。
- 时辰"不知道"时原型会先按午时排；插件里不替用户默认。
- 界面是直接拼 DOM 字符串写的；插件里是 React。

完整清单见 spec 第 4 节。
