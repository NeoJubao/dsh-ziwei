# 工作台 v4 · 信息架构与交互重构

日期：2026-11-11
状态：本地已实现，未发版（版本号由维护者在发布前决定）
关联：`docs/ui-contract/layout.md`（v4）、`docs/ui-contract/design.md`（字阶）、
`src/ui.css`（设计系统）、`src/ui-pro.js`（应用壳与页面）

## 1. 背景

用户反馈三件事：

1. 工作台整体信息结构和功能结构还可以再优化：首页应该能直接看到**最近看过的盘 / 已保存的盘**，
   点进去继续看，或者直接新建一张。
2. 「紫微师解读」应该是**先进入聊天界面**，有引导，再生成完整报告；报告生成后能预览、能全屏阅读。
3. 整体布局、交互与视觉参考**自媒体工作台**（`dsh-media-desk`，MIT）里做得好的部分，
   有能复用的组件/范式就复用。

## 2. 参考对象：自媒体工作台里可迁移的交互

| 可迁移范式 | 在 v4 的落点 |
|---|---|
| 浮空玻璃顶栏 + 胶囊页签（品牌 / 页面 / 上下文 / 全局动作） | `HEAD`：品牌（点击回首页）+ 首页/命盘/解读/报告导航 + 当前命主 chip + 返回会话 + 设置 |
| 页面级滚动 + 大留白（`page` 绝对定位、内容 1160 上限） | 首页 / 新建 / 命盘页统一 `.zp-page` + `.zp-page-inner` |
| 轻量大标题（300 字重、34px） | 首页 Hero、命盘页命主名、新建页标题 |
| 卡片 + 胶囊动作 + 极轻阴影，不靠边框分区 | 我的命盘卡片、报告完成卡、信息卡；动作统一 `zp-pill` |
| 工位式双栏（左聊天 / 右产物） | `READING`：`CHAT` 380 + `REPORT_DOCK` flex；窄屏用「对话 / 报告」tabs |
| 产物卡的状态（空 → 生成进度 → 完成 → 阅读） | 报告工位：生成入口 → 14 段进度/字数 → 完成卡（全屏阅读/导出/复制） |
| 沉浸式阅读（全宽纸张、顶部轻工具条） | `READER`：860px 报告纸张 + 返回解读 / 全屏 / 导出 / 复制 |

**没有直接 import 它的代码**：`dsh-media-desk` 是独立插件、组件在其 bundle 内部，插件之间不能互相 import；
宿主 `dsh-client-ui-primitives` 也不是外部插件的稳定 import（是 shell 的 build input）。
因此复用的是**设计 token / 交互范式**，组件在插件内实现；四柱、宫格、格局、词典等继续复用本插件既有组件。

## 3. 信息架构：五页 + 一个浮层

```
首页 HOME ──新建──▶ 新建 CREATE ──排盘──▶ 命盘 CHART ──解读──▶ 解读 READING ──生成报告──▶ 报告 READER
   ▲                                              │                 │                      │
   └──────────── 顶栏导航 / 报告完成后可直达 ◀──────┴─────────────────┴──────────────────────┘
设置 MODAL：任意页叠加
```

- **导航**：`HEAD` 顶栏胶囊页签，`首页 / 命盘 / 解读 / 报告`；「报告」只在已生成过报告时出现；
  未出盘时「命盘 / 解读」禁用并提示先新建。
- **页面之间不共享滚动**：每页独立滚动，切换页保留当前命盘与解读状态。
- **退役**：左栏（命主/格局/表单/命盘库四张卡）、解读抽屉、报告预览浮层、窄屏底栏、专注看盘。

## 4. 关键页面

### 4.1 首页

- Hero：eyebrow + 「把一张命盘，读成一条人生路线。」+ 统计（已保存 N 张 / 最近看过 M 张 / 上次）。
- 动作：`新建命盘`（主）/ `示例命盘`（次）。
- 「我的命盘」网格：历史记录 + 已保存合并去重，按最近查看排序；卡片显示命宫地支、四柱、五行局、
  最近时间、已保存/最近标签；点卡片直接进入命盘；星标保存/取消，未保存的历史可移除；最后一格是「新建一张」。
- 空态：一句说明 + 新建入口。

### 4.2 新建 / 改生辰

- 表单卡：姓名、历法、年月日、时间/性别、经度/籍贯/职业、流派设置；两列表单，窄屏单列。
- 侧卡：「你会得到」（命盘/格局/解读/报告/精装 HTML）与「排盘与隐私」。
- 底部：`排盘并查看` + `用示例生辰`；错误就近显示。

### 4.3 命盘页

- Hero：本命盘 · 五行局 · 阳男；命主名 + 生肖/时辰；公历/农历/四柱/命宫身宫/起运 chips；
  动作：`解读这张盘`（主）、`保存命盘`、`改生辰`、复制命盘、写入会话。
- TimeBar：本命/大限/流年 + 时间步进 + 格局/词典 + 杂曜开关；工具视图有返回盘面出口。
- 盘面 + 宫位详情（wide 并列 300，mid/narrow 下沉）；键盘 ←→↑↓ 仍可用。
- 盘面下方：`SIDE_PROFILE`（命主信息）+ `SIDE_PATTERNS`（格局摘要）两张信息卡。

### 4.4 解读页

- 左 `CHAT`：头部（返回命盘 / 标题 / 上下文 / 交给会话 / 新对话）；空态欢迎语 + 四条引导
  （事业财运、大限、性格、完整报告）；对话流（用户气泡 + 紫微师回答，回答内 markdown 表格/引用/列表）；
  输入框 + Enter 发送 / Shift+Enter 换行 + 免责声明。
- 右 `REPORT_DOCK`：空态「把这盘读成一份完整报告」+ 14 部分清单 + 生成按钮；
  生成中：章节进度（当前章节 / 14 段进度条 / 字数 / 停止）；完成：报告卡（14/14、字数、时间、
  全屏阅读 / 导出 HTML / 复制 / 重新生成）+ 摘要预览。
- 窄屏：单栏 + 顶部「对话 / 报告」tabs；生成报告自动切到报告页签。

### 4.5 报告阅读

- 顶栏：返回解读、报告标题/字数/时间、全屏、导出 HTML、复制全文。
- 860px 居中纸张（iframe，隔离报告样式），滚动阅读；`requestFullscreen` 可用时进入浏览器全屏。
- 无报告时给空态与返回解读。

## 5. 数据与状态

- `ziwei-pro.form`：表单（沿用）；`ziwei-pro.library`：已保存命盘（沿用结构）。
- `ziwei-pro.history`（新增）：最近看过（按输入去重、最多 16 条、自动记录排盘/载入）。
- 阅读状态：`thread`（聊天问答）、`report`（`idle | running | error | done` + 文本/字数/时间/错误/可继续）；
  报告生成走独立 SSE 分支，不把 13k 字报告塞进聊天。
- 页面状态：`page = home | create | chart | reading | report`；`readingTab = chat | dock`（仅窄屏生效）。
- 换盘时清空当前解读与报告，避免旧内容串到新盘；历史与保存不受影响。

## 6. 设计系统

- 颜色：全部走宿主 `--dsw-alias-*`；内容色（星曜/四化/庙旺/金）保留 `--zp-*` 并有明暗两套。
- 字阶：新增展示级（34/28/25/24/20/17/16/15），正文 14/13.5/13/12.5/12，辅助 11.5/11/10.5/10；
  盘面数据子阶保留 9.5/9/8.5/7.5（见 `design.md`）。
- 字重：新增 300 用于展示级；400–700 用于正文与数据。
- 间距：继续 4/8 网格（2px 半档用于图标与角标），审计 C3 棘轮只降不升。
- 圆角/阴影：`--dsw-radius-*` 与 `--dsw-elevation-soft/prominent`；卡片靠阴影与表面色，不堆描边。

## 8. 已知限制

- 报告文本与聊天记录只在内存中保留：刷新页面/切盘后不恢复（历史命盘会恢复）。
- 全屏阅读依赖宿主 webview 的 Fullscreen API；不可用时静默降级为面板内全屏。
- 窄屏盘面仍是 4 列布局，极窄（< 560）仍靠字号缩放，后续可加横向滚动。
- 外部插件不能 import `dsh-media-desk` 或宿主 primitives，故只复用范式与 token。
