## 1. 宽度矩阵（最优先，半小时）

**怎么调宽度**：拖 DSH 侧栏边界 / 折叠侧栏 / 拉窗口。每档都要同时看"布局档位"和"内容是否被拉伸"。
档位公式（设计值）：`narrow < 952 ≤ mid < 1436 ≤ wide < 1536 ≤ xwide`；盘面 `560 ≤ W ≤ 720`（xwide ≤800）。

| 目标面板宽 | 期望档位 | 期望看到 | 通过标准 |
|---|---|---|---|
| ≥1536（可折叠侧栏到全宽） | xwide | 左栏 320 固定；盘面 800 居中；详情 320 与盘面仅隔 24；抽屉打开 520 不铺满 | 盘面**没有**随窗口继续变大；两侧留白对称；顶栏不换行 |
| 1436–1535 | wide | 盘面 720；详情 300 并列 | 三个上限同时成立 |
| 1200 | mid | 详情**下沉**到盘面下方；盘面 720 居中 | 不出现右侧详情列；盘面两侧留白相等 |
| 1000 | mid | 盘面随宽度收缩（约 608）；左栏 320 | 盘面不溢出、不横向滚动 |
| 952 附近 | mid↔narrow 边界 | 只切换一次档位；不出现来回闪 | 缓慢拖过 952 时无抖动/闪烁 |
| 900 | narrow | 无左栏；TimeBar 两行；底栏出现；盘面 720 居中 | 底栏不遮内容；TimeBar 不滚走 |
| 700 | narrow | 盘面约 652；底栏三键 | 按钮不换行挤压 |
| 608 附近 | narrow 边界 | 盘面开始横向滚动；出现「可左右拖动」提示 | 能滚动看到第 4 列宫格；提示可见 |
| 480 | narrow | 盘面 560 可横向滚动；底栏占满；抽屉全宽 | 无水平页面滚动条（只有盘面容器内滚） |

- [ ] 9 行全部核对；边界三处（952 / 1436 / 608）单独过一遍
- [ ] **全宽不松散**三条硬指标：① 左栏宽仍 320；② 盘面 ≤800；③ 抽屉 ≤520 且左侧仍能看到盘面

## 2. 外壳与滚动（15 分钟）

逐项看「滚动时谁不动」：

- [ ] **AppBar 不动**：滚动盘面时顶栏始终可见；darwin 下不被红绿灯遮挡（看品牌名左侧）
- [ ] **TimeBar 不动/不滚走**：滚动长详情时，本命/大限/流年与运限导航始终可见
- [ ] **左栏独立滚动**：滚左栏（表单/库）时盘面不动；滚盘面时左栏不动
- [ ] **详情独立滚动**（wide+）：Inspector 内容超长时自身滚，不影响盘面
- [ ] **没有页面级滚动条**：滚动条只出现在 rail / 盘面 / 详情 / 抽屉内容区（如果仍是一条页面滚动条，记录为"未拆分区"）
- [ ] 首帧不闪跳：切换会话/重新打开面板时，不出现"先窄版再变宽版"的跳变
- [ ] 专注看盘：点「专注」→ 左栏与详情隐藏、盘面到 820、**TimeBar 仍在**；退出恢复原档；无盘时按钮不出现或不可用
- [ ] 缩小窗口不出现横向页面滚动（窄于 608 时只有盘面容器内滚）

## 3. 时间维度导航（重点，半小时）

### 3.1 默认与当前

- [ ] 出盘后默认在**本命**；切到「大限」时默认停在**当前大限**（不是第 1 段）；切到「流年」默认**今年**
- [ ] 当前段有「当前 / 今」标记；当前年有「今年」标记
- [ ] 从命盘库载入另一张盘 → 大限/流年回到**该盘**的当前段/今年（不继承上一张盘的选择）

### 3.2 大限导航

- [ ] 显示完整：`第 N 段 · 年龄区间 · 干支 · 宫位`（四要素齐全）
- [ ] `‹` 在第 1 段禁用、`›` 在第 12 段禁用；**不循环**
- [ ] 非当前段时出现「回到当前」，点击回到当前段；当前段时该位置显示「当前」而非按钮
- [ ] 下拉可跳到任意 12 段，选项里当前段有「（当前）」标识
- [ ] 切换大限：盘面限宫名/限星/限四化角标同步变化； Inspector 的「本限四化」同步（4 条：星 + 化 + 宫位）
- [ ] **不再有**十二大限卡片列表、年份输入框出现在盘面上方
- [ ] 键盘：焦点在导航组内 `←/→` 上一/下一段、`Home` 回到当前；**焦点在页签上按 ←/→ 不会切宫位**

### 3.3 流年导航

- [ ] 显示：年份 + 干支 + 小限虚岁 +（非今年时）「今年」
- [ ] `‹/›` 逐年前后；`Shift+←/→` ±10 年；`Home` 今年
- [ ] 边界：可排范围外（<1900 或 >2100 / 超出 120 年）时按钮禁用，不出现空白盘
- [ ] **非法/越界输入不摧毁盘面**：手输 1899 或乱码 → 保留上一张有效盘 + TimeBar 内联提示，不出现"整个盘面变错误条"
- [ ] 流年星曜角标、Inspector 流年四化同步

### 3.4 与解读联动

- [ ] 在大限 33–42 岁下打开「紫微师解读」：抽屉头部显示上下文 chip「大限 第4段 33–42岁 甲辰 田宅」
- [ ] 在流年 2035 下打开解读：chip 显示「流年 2035 …」；**问"这年怎样"回答针对 2035**（不再答今年/命格总纲）
- [ ] 解读进行中切换大限/流年：出现「上下文已切换，可点重新解读」提示；**不自动重跑**
- [ ] 建议问题按模式变化（大限模式出现"这个大限要注意什么"）

## 4. 按钮层级（20 分钟）

**方法：每个状态截图，只看"品牌填充色出现在哪"，应恰好一处。**

| 状态 | 唯一主行动 | 检查 |
|---|---|---|
| 无盘 | **排 盘**（左栏表单 / 窄档底栏） | 顶栏解读不可用（禁用，且有 title 说明）；空态 CTA 是次按钮 |
| 有盘 | **紫微师解读**（顶栏右端 / 窄档底栏） | 左栏「排盘」已降为次按钮，不是同款填充大按钮 |
| 抽屉开·空闲 | **发送** | 顶栏解读变为次级/按下态，不与发送抢主行动 |
| 抽屉开·流式 | **停止** | 发送不可用；其他操作禁用但仍可见 |
| 抽屉开·有错误 | **继续生成** | 已生成文本保留 |
| 设置开 | **无主行动**（关闭是出口） | 弹层内没有填充主按钮 |
| 排盘失败 | **排 盘**（重试） | 错误条指明字段 |

- [ ] 表格 7 行逐行核对
- [ ] **全量按钮摸一遍**：每个按钮有 hover / 按下 / 焦点环 / 禁用态；禁用有 title 原因
- [ ] 复制 / 写入上下文：一步可达（顶栏图标；宽档带文字、窄档进「更多」）
- [ ] 设置：全局唯一位置（顶栏最右；窄档在「更多」）
- [ ] 工具（格局 / 词典）：在 TimeBar 右侧，点击后当前项高亮，可一键「返回盘面」
- [ ] 删除命盘：只有行尾图标，hover 才变危险色；不出现红色大按钮
- [ ] 文案一致性：不再同时出现「紫微师解读 / 紫微师·直接聊 / 新会话解读」三种叫法；模式叫「速览 / 鲲鹏报告」
- [ ] 窄档底栏：`[生辰][更多][主行动]` 三键；按钮高度够手指（≥40）；不遮最后一行内容

## 5. 状态与反馈（15 分钟）

逐条触发：

- [ ] **空**：无盘 → 太极 + 一句说明 + 示例 CTA；示例可点出盘
- [ ] **排盘失败**：把日期改成 2 月 31 日 / 年份 1800 / 点击排盘 → 错误条写明改哪个字段；焦点跳到非法字段
- [ ] **流年越界**：见 §3.3
- [ ] **解读流式**：有打字行 + 字数 + 停止；读屏可播报（VoiceOver 打开听一句）
- [ ] **用户停止**：点停止 → 已生成内容保留 + 错误条「已停止…继续生成」；点继续接着写、不重复
- [ ] **断流**：拔网/断流 → 区分"中断"文案；已生成不丢
- [ ] **命盘库空**：显示「暂无保存的命盘」，区域不消失
- [ ] **工具空结果**：格局/词典搜不到时给一句空文案，不隐藏区域
- [ ] **视图切换**：格局/词典与盘面不同屏；返回盘面 1 次点击
- [ ] **渲染崩溃兜底**（可选）：DevTools 里故意抛错 → 错误边界 + 重试，不白屏

## 6. 明暗主题（10 分钟）

- [ ] 系统切到深色：所有面板/卡片/输入/分隔线跟随，没有残留浅色块
- [ ] 品牌填充按钮上的文字可读（不再白字压浅紫）；选中的页签/胶囊同样
- [ ] 星曜/四化/庙旺角标在深色下**提亮一档**后仍可读；四化角标不糊成一块
- [ ] 金色字（起运/大限岁数）在深色下不暗到看不见
- [ ] 分隔线密度：深色下栏/区块分隔线不"脏"（过亮或过密）
- [ ] 流式文本、错误条、禁用态在两套主题下都可辨识

- [ ] 顶栏内容不被红绿灯/标题栏遮挡（品牌名左缘与红绿灯有间距）

- [ ] 设置弹层：顶部不被窗口标题带压住；`Esc` 可关；关闭后焦点回到"设置"按钮

## 8. 键盘与读屏（15 分钟）

只按键盘走一遍全流程：

- [ ] Tab 顺序：顶栏 → 左栏（表单/库）→ TimeBar → 盘面 → 详情 → 底栏（窄档）；顺序与视觉顺序一致
- [ ] 焦点环：**所有**可聚焦元素都可见（重点：分段控件、命盘库列表项、TimeBar 步进按钮）
- [ ] 页签：`←/→` 切本命/大限/流年，`aria-selected` 同步；**不会**同时切宫位
- [ ] 宫位：焦点进盘面后 `←/→` 环上移宫、`↑/↓` 跳对宫；焦点在输入框时不劫持方向键
- [ ] 时间导航：`←/→` 步进、`Home` 回到当前/今年；边界处按键无反应（不越界）
- [ ] 抽屉/设置/窄屏 sheet：打开时焦点进入；Tab 在层内循环；`Esc` 关闭；关闭后焦点回到触发按钮
- [ ] 遮罩打开时背景不可 Tab 到（若仍可，记录为待改进）
- [ ] VoiceOver：解读流式内容有播报；图标按钮读出中文名称（不是"按钮"）
- [ ] 复制/写入成功提示可被读屏播报（`role=status`）

## 9. 窄屏专章（10 分钟）

- [ ] 无盘：表单内联首段；底栏主行动=排盘；示例 CTA 可点
- [ ] 有盘：表单折叠成一行「生辰摘要」；点「生辰」从左滑出表单 sheet；`Esc`/遮罩关闭
- [ ] 点宫位：底部 sheet 打开（≤72% 高），内容与 wide 详情一致（含对宫/三合/运限）
- [ ] sheet 打开时底栏不可误触；关闭后焦点回到被点的宫位
- [ ] 「更多」菜单恰好 4 项：复制命盘 / 写入上下文 / 命盘库 / 设置；点空白关闭
- [ ] 工具视图：TimeBar 变「返回盘面」条；词典可搜索、分页可加载
- [ ] 盘面横向滚动：能拖到最右宫格；提示文案出现且不挡内容
- [ ] 抽屉：全宽、可关闭、输入框不与底栏重叠（键盘弹起时）

**阻止合入的判定（任一即不通过）**

1. 全宽时盘面/左栏/抽屉被拉宽（违反 §1 三条硬指标）；
2. TimeBar 会滚出视口，或时间范围变化后盘面数据不同步；
3. 同一屏出现两个品牌填充按钮；
4. 流年非法输入导致盘面消失/空白；
5. 窄档底栏遮住内容或点不到；
6. 弹层打开后键盘焦点可跑到背景且关不回来；
7. 回归清单里任一 v2 能力不可用。
