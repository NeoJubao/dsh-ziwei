# 界面 v3.2 · 解读抽屉降噪与精装报告表格

日期：2026-11-11
状态：本地已实现，未发版（版本号由维护者在发布前统一决定）
关联：`docs/ui-contract/layout.md` §2 `DRAWER`、`docs/ui-contract/design.md`、`src/ui-pro.js`

## 1. 背景（三条用户反馈）

1. **导出的「鲲鹏精装 HTML」里 markdown 表格没渲染**：报告正文里的管道表格被当成普通段落，
   导出的 HTML 上直接显示 `| 巳 · 仆役（癸巳） | … |` 和 `|---|---|---|`。
2. **抽屉头部两个分段按钮「速览解读 / 鲲鹏报告」点了没反应**：它们只改「下一次请求」的模式，
   不发起任何动作，切换结果也没有可见产出，用户分不清这两个按钮和主行动的关系。
3. **抽屉信息密度大、噪音多**：头部有标题 + 副标题 + 两个模式按钮 + 新对话 + 关闭；
   空态有重复标题 + 两段说明 + 三条建议；底部有四个文字工具 + 两行输入提示 + 三行免责声明。

## 2. 决策

### 2.1 报告渲染器补 GFM 表格（P0）

- `mdToHtml` 支持管道表格：表头、对齐（`:--` / `--:` / `:-:`）、单元格内 `<br>`、行内加粗与
  `` `code` ``；单独一行的 `---` / `***` / `___` 输出 `<hr>`；标题层级收口到 `h2–h4`。
- 新增 `.md-table` 样式（1px 描边、表头纸色底、单元格上对齐、`word-break`），
  表格行 `page-break-inside: avoid`，A4 打印不切断行；补 `ul/ol/li/hr/code/h4` 的基础样式。
- 渲染器仍是纯字符串函数（无 React / DOM 依赖），以 `window.ZWReport` 暴露
  （与既有 `window.ZWEngine` / `window.ZWCore` 同一形态），供 `verify/verify.mjs` 直接断言。
  不引入任何前端 markdown 依赖；只覆盖报告实际会用到的 GFM 子集。

### 2.2 两个模式按钮 → 两个「真动作」

- **删除抽屉头部的「速览解读 / 鲲鹏报告」分段**。它是选项，不是动作；放在品牌主行动旁边
  会被读成按钮，点了却没有产出。`DRAWER` 区域不再放模式切换。
- 空态只留一句话 + 两个**一次点击就产出内容**的动作：
  - `速览解读`（primary）→ 直接发起 brief；
  - `完整鲲鹏报告`（secondary）→ 直接发起 report。
- 回答完成后，若当前对话还没有出过完整报告，工具条出现 `完整报告` 动作（真发起 report）；
  已经出过完整报告后不再出现，避免重复生成。
- 首次点「紫微师解读」打开抽屉、且当前还没有对话时，直接发起一次速览解读
  （每张盘只自动一次）；用户随后可以追问或点 `完整报告`。这样「紫微师解读」这个按钮
  本身就有可见结果，不依赖用户再找入口。（**v3.3 已撤回**，见第 5 节）
- 换盘（重新排盘 / 载入命盘库）时清空上一张盘的对话与 `hasReport`：解读对象变了，
  旧回答不能串到新盘上；同时为新盘保留一次自动速览。

### 2.3 抽屉降噪

- **头部**：图标 + `紫微师解读` + 新对话（有对话时）+ 关闭；删除副标题与模式条。
- **空态**：删除重复标题、引擎说明、三条建议；保留一行说明 + 2.2 的两个动作。
- **工具条**：复制 / 预览 / 导出改为图标按钮（`title` + `aria-label`），`完整报告` 与
  `新会话解读` 保留文字；只在有回答时出现。窄档下同一套按钮不放文字。
- **输入区**：placeholder 收成一句；免责声明压成一行短句（完整版本仍在导出的报告里）。
- **不变**：对话流 `role=log` + `aria-live`、浮层焦点陷阱、`PREVIEW` 子层、Esc 逐层关闭、
  `禁用（未出盘时解读）` 的「点了无反应」禁令。

## 3. 不做

- 不改排盘 / 解读提示词、模型与 maxTokens（report 仍为 32768）。
- 不做后台轮询或自动重复生成；自动只发生在「每张盘首次打开抽屉」一次。（**v3.3 已撤回**：不再有任何自动生成）
- 不新增 RegionId、不新增字号 / 颜色档位；样式只复用 `--dsw-alias-*` 与 `--zp-*` 现有 token。

## 5. 附：v3.3 修订（2026-11-15）

**撤回自动速览。** 用户反馈：点开「紫微师解读」就开始解读，不是他要的——他可能只想先看盘，
或者先问自己的问题，而生成已经跑起来、还得等、还要花一次模型调用。

- 点开抽屉只做一件事：把当前盘带进空态。`速览解读` / `完整鲲鹏报告` / 输入框追问，
  全部由用户点。
- 删除 `autoStartedRef` 与 `openAI` 里的 `runInterpretation('', 'brief')`；
  换盘清空对话与 `hasReport` 的重置保留（不串盘）。
- 空态按同一轮反馈重做：旧版把两个 `.zp-btn` 用 `flex: 1 1 0` 拉成半屏宽、高度只有 32，
  图标（`svg display:block`）落在最左、文字居中，外面还有虚线框，整块悬在面板正中。
  现在是一行一个动作卡：30px 图标块 + 名称 + 11px 说明 + 右侧 14px 箭头，卡片
  `padding: 12`、`gap: 12`，块宽 `max-width: 420` 居中，首选项只加品牌色描边与浅底。
  文案拆成 lead「命盘已带入」+ hint「直接提问，或先看一份解读。」。
- 断言同步：`verify/verify.mjs` 由「首次打开自动发起」改为「点开不自动发起」，另加一条
  「空态是动作卡、不再用 `flex: 1 1 0` 拉满整行」防回退。
- 教训：别把「花钱 + 等待」的动作挂在打开浮层这类入口上；入口只负责把上下文带进来。
