# 0003：紫微师改成右侧面板（宽屏并排），报告成为顶栏的一个页签

- 状态：已采纳（分支 `feature/v6-redesign`，未发布）
- 日期：2026-11-19
- 决策人：Neo（看过 v6 原型第 2–4 版后确认"整体没问题"，功能收束"以原型为准"）
- 相关：`docs/specs/2026-11-19_v6-redesign.md` §3.4、§3.5、§4.6；取代 [0002](0002-reading-in-right-drawer.md)

## 背景

0002 决定解读用右侧抽屉（560px，带遮罩），报告是抽屉里的一个页签，另有"阅读模式"和"全屏"；宽屏并排在 dogfood.1 试过后撤回。0002 自己记下了代价和重新考虑的条件：抽屉打开时盘面被遮罩挡住，对照盘面和报告要来回开关。

v6 从零重做界面。Neo 明确喜欢 dsh-media-desk 的右侧助手面板，并在原型里连续三版看到"宽屏并排、窄屏浮出"的紫微师面板和独立的报告页，没有提出异议。

和 dogfood.1 相比，这次的前提变了：

- dogfood.1 的并排是"左边对话、右边画布"，盘面被挤到画布里，成了配角。v6 里盘面留在原位，只是变窄；盘面按容器宽高比伸缩，变窄后仍然一屏放完。
- 完整报告有 14 个部分，在 464–560px 宽的抽屉里读长文太挤，所以 v5 才又加了"阅读模式"和"全屏"，一份报告有三个地方可以看。

## 决定

1. 紫微师是右侧面板，宽 360px。面板宽度不小于 1180px 时和命盘并排，不遮挡盘面；小于 1180px 时浮在命盘上，带遮罩，行为和原来的抽屉一样。
2. 报告是顶栏页签里的一项（本命 / 大限 / 流年 / 流月 / 流日 ｜ 报告）。点进去，左栏是目录，右边是阅读栏；写的过程中文字直接出现在阅读栏里。去掉抽屉里的报告页签、阅读模式和全屏。
3. 读报告时紫微师面板仍然可以打开；选中一段正文可以带着它去问。

## 为什么没选别的

| 方案 | 没选的原因 |
|---|---|
| 维持 0002（抽屉 + 抽屉里的报告页签） | 对照盘面和解读要来回开关；长报告在抽屉里太挤，靠再加两个入口补救 |
| 报告放进紫微师面板 | 360px 读 14 个部分的长文更挤 |
| 任何宽度都并排 | 面板窄于 1180px 时，盘面会被挤到 520px 以下，字看不清 |

## 后果

- 好处：宽屏下盘面和对话可以同时看；报告只有一个地方；报告页有足够的行宽。
- 代价：宽屏下打开面板，盘面会变窄一次（有 180ms 的过渡）；顶栏多一个页签，窄档下六个页签挤在一行。
- 什么情况下要重新考虑：dogfood 反馈并排时盘面太小；或者窄档下六个页签点不准。
